Ніколи не комітити і не пушити без явного дозволу користувача.

**Why:** Користувач сам вирішує коли публікувати зміни.
**How to apply:** Після змін повідомляти що готово і питати "Закоміти і запушити?" або чекати команди "так".

---

При `git push` спочатку робити `git pull --rebase`, бо в репо є автоматичні коміти (chore: update products/posts).

**Why:** Пуш часто відхиляється через розходження з remote.
**How to apply:** Використовувати `git pull --rebase && git push` як стандартний патерн.
